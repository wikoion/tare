# Tare

Open-source Kotlin Multiplatform app for the Etekcity ESF-24 and ESF-551 scales. README.md describes
the project and docs/PROTOCOL.md the protocol.

## Layout
- `core/`: KMP library (jvm + iOS): protocol (`tare.protocol`), body composition (`tare.body`),
  units, SQLDelight storage (`tare.data`). No UI, no Bluetooth.
- `composeApp/`: Compose Multiplatform UI, Kable BLE (`tare.ble.ScaleManager`), Apple Health
  interface (`tare.health`). Platform code is behind `expect` in `tare/platform/Platform.kt`.
- `iosApp/`: SwiftUI shell + `HealthKitBridge.swift`, generated by XcodeGen from
  `iosApp/project.yml`. Don't commit the generated `.xcodeproj`.

## Toolchain
- `export JAVA_HOME=/opt/homebrew/opt/openjdk@21`; `unset CC CXX` before xcodebuild (Homebrew clang breaks it).
- Tests: `./gradlew :core:jvmTest` (fast). Compile check: `./gradlew :composeApp:compileKotlinIosSimulatorArm64`.
- Simulator: `cd iosApp && xcodegen generate`, then
  `xcodebuild -project iosApp/Tare.xcodeproj -scheme Tare -destination 'platform=iOS Simulator,name=iPhone 16 Pro' -derivedDataPath iosApp/build/DerivedData build`.
  Launch with `-demoData` (separate DB, synthetic history); see docs/DEVELOPMENT.md for the other debug arguments.
- Device: `scripts/install-app.sh` (needs `iosApp/Config/Local.xcconfig`).
- Bluetooth log: every line also goes to `Documents/bluetooth-log.txt` (plus `bluetooth-log.1.txt` once it passes 2 MB).
  Pairing logs each nearby device's advertisement. Read it off the phone with `xcrun devicectl device copy from
  --domain-type appDataContainer --domain-identifier <your bundle ID> --source Documents/bluetooth-log.txt`;
  this works on TestFlight builds too.
- TestFlight: `scripts/testflight.sh` archives a Release build and uploads it with the Apple ID signed in
  to Xcode. App Store Connect takes only iOS 26 SDK builds, and macOS 15 can't run Xcode 27, so the script
  uses the side-by-side `/Applications/Xcode-26.3.0.app`; `/Applications/Xcode.app` stays the default.
  The app is iPhone only (`TARGETED_DEVICE_FAMILY` 1): as a universal app, portrait-only fails the iPad
  multitasking check. The build number is the UTC date and time. `iosApp/Tare/PrivacyInfo.xcprivacy`
  declares the required-reason APIs the binary uses (the Kotlin framework's stat/fstat, NSUserDefaults);
  App Store Connect rejects an upload that uses one it doesn't list, so re-check after adding libraries.

## Rules
- Kable's `Bluetooth.availability` is deprecated at error level; Bluetooth state comes from
  `bluetoothState()` (own CBCentralManager on iOS).
- The protocol and body-composition code is an independent Kotlin port of the MIT
  `etekcity_esf551_ble` library, credited in THIRD_PARTY_NOTICES.md. Don't paste code from other
  projects. Credit protocol facts, formulas and test vectors in THIRD_PARTY_NOTICES.md.
- Test frames must be real captures or synthetic. Never commit a user's personal readings.
- The UI takes inspiration from the vendor app's layout but uses its own palette, icons
  (`TareIcons`), wording and artwork. Don't copy the vendor's assets or text.
